## What is DmarcForge?

DmarcForge provides browser-based tools for DMARC-related tasks while keeping the workflow on the local device. Its local-first approach is useful when access to an online service is unnecessary or unavailable.

The application consists of one HTML file and has no external dependencies. As a result, it can be downloaded, kept locally, and opened in a compatible browser with very little setup.
